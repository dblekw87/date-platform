# Korean User Assumptions

## 기본 질문

한국 투자자는 투자 서비스를 처음 열었을 때 무엇을 가장 먼저 확인하고, 어떤 순서로 정보를 탐색하며, 어떤 표현을 가장 쉽게 이해하는가?

## 사용자 가설

1. 첫 화면에서는 오늘 시장 분위기와 주요 지수를 먼저 확인한다.
2. 시장이 왜 움직였는지 확인할 수 있을 때 다음 화면으로 이동한다.
3. 종목명, 종목 코드, 테마, 업종, 뉴스 키워드로 탐색을 시작한다.
4. 인기 종목과 거래대금 상위는 친숙한 진입점이지만, 투자 판단 근거로 받아들이면 위험하다.
5. 투자 근거와 해석을 구분해서 보여주면 신뢰가 높아진다.
6. 영어 UX 용어보다 설명형 한국어 문장이 이해하기 쉽다.
7. 모바일에서는 목록, 탭, 하단 행동 영역, 검색 접근성이 중요하다.
8. 초보자는 “무엇을 봐야 하는지”를 원하고, 숙련 사용자는 “근거와 한계”를 빠르게 확인하려 한다.
9. 사용자는 가격 변동보다 “왜 움직였는가”와 “아직 확인되지 않은 것은 무엇인가”를 알고 싶어 한다.
10. 투자 추천처럼 보이는 문구는 불신을 만든다.

## 주요 사용자 상황

### 장 시작 전

- 오늘 시장 분위기와 주요 일정 확인
- 관심 종목에 새 변화가 있는지 확인
- 전날 판단에서 바뀐 근거가 있는지 확인

### 장 중

- KOSPI, KOSDAQ, 미국 주요 지수, 환율, 테마 흐름 확인
- 거래대금 상위, 상승·하락 종목, 주목 테마 확인
- 움직인 이유와 확인된 투자 근거 확인

### 장 종료 후

- 오늘 판단과 근거 정리
- 새로 확인할 내용 기록
- 다음에 다시 봐야 할 조건 확인

## 사용자 불안 요소

- 정보가 너무 많아 무엇부터 봐야 할지 모름
- 영어 용어와 전문 용어가 많아 화면을 해석해야 함
- 인기 종목과 추천 종목의 경계가 흐림
- 출처와 확인 시점이 없어 신뢰하기 어려움
- AI 해석이 근거처럼 보일 때 판단을 오해할 수 있음

## 설계 대응

- 첫 화면에 “오늘 먼저 볼 것”을 명확히 둔다.
- 시장 정보에서 투자 근거로 이어지는 길을 만든다.
- 출처, 마지막 확인 시점, 아직 단정할 수 없는 내용을 쉬운 말로 보여준다.
- 투자 추천과 수익 보장으로 읽히는 문구를 금지한다.
- 모바일에서 한 손으로 주요 흐름을 따라갈 수 있게 한다.
