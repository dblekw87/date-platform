# Korean UX Principles

## 원칙 요약

1. 시장에서 시작하되 근거로 끝난다.
2. 화면은 용어를 가르치지 않고 내용을 설명한다.
3. 인기와 등락은 진입점일 뿐 판단 근거가 아니다.
4. 카드보다 목록, 탭, 요약, 표를 우선 검토한다.
5. 다음 행동을 사용자가 고민하지 않게 한다.
6. 모바일에서 먼저 자연스러워야 한다.
7. 전문적이지만 어렵지 않은 어조를 유지한다.
8. 투자 근거와 해석은 항상 구분한다.

## 정보 흐름 원칙

기본 흐름은 다음 순서를 따른다.

시장 변화 → 관련 테마 → 관련 종목 → 움직인 이유 → 확인된 투자 근거 → 아직 확인되지 않은 내용 → 분석 또는 기록

## 화면 구성 원칙

- Home은 Dashboard Widget 나열이 아니다.
- 시장 화면은 단순 순위표가 아니다.
- 종목 상세는 가격과 차트가 전체를 지배하지 않는다.
- 투자 근거 상세는 기사 상세가 아니다.
- 분석은 AI 채팅이나 메모장이 아니다.
- 변화는 가격 알림 목록이 아니다.
- 기록은 수익률 중심 매매일지가 아니다.

## 카드 사용 기준

카드는 다음 경우에만 사용한다.

- 대표 콘텐츠를 강조할 때
- 하나의 독립 주제를 묶을 때
- 행동이 명확히 필요한 묶음일 때
- 모바일에서 정보 단위를 구분해야 할 때

목록 또는 행을 우선하는 정보는 다음과 같다.

- 종목 목록
- 투자 근거 목록
- 출처 목록
- 새롭게 감지된 변화
- 판단 기록 목록
- 관련 테마
- 최신 정보
- 검토 대기 항목

## Emotion Layer 원칙

Emotion Layer는 감정 자극이 아니라 이해를 돕는 안내 문장이다.

허용 예:

- 오늘 시장은 이 세 가지를 확인하세요.
- 이 변화가 중요한 이유
- 투자 판단 전에 확인할 내용
- 아직 확인되지 않은 부분
- 새로운 근거가 추가됐어요.
- 정보가 오래되어 다시 확인이 필요해요.

금지 예:

- 지금 매수하세요.
- 놓치면 안 되는 종목
- 무조건 오를 종목
- 급등 예상
- 오늘의 대박주
- AI가 추천하는 종목

## 평가 기준

- 첫 화면을 5초 안에 이해할 수 있는가
- 영어 UX 용어 없이도 사용할 수 있는가
- 오늘 무엇을 봐야 하는지 알 수 있는가
- 시장 정보에서 투자 근거로 자연스럽게 이동하는가
- 투자 근거와 해석을 구분할 수 있는가
- 아직 확인되지 않은 내용을 쉽게 찾을 수 있는가
- 다음 행동이 명확한가
- 모바일에서 한 손으로 주요 흐름을 사용할 수 있는가
- 카드가 과도하게 반복되지 않는가
- 투자 추천이나 수익 보장처럼 보이지 않는가
- 초보자에게 친절하면서 숙련 사용자에게도 정보가 부족하지 않은가
