# Korean Navigation Options

## 목표

Global Navigation은 사용자가 목적을 즉시 이해할 수 있어야 한다. 종목과 투자 근거는 중요한 대상이지만 독립 Global Navigation보다 검색, 시장 화면, 종목 상세, 관련 콘텐츠에서 진입하는 것이 적합하다.

## 후보 1

- 홈
- 시장
- 분석
- 변화
- 기록

장점:

- 메뉴 수가 적고 모바일 하단 메뉴로 바로 사용할 수 있다.
- 화면 목적이 동사와 작업 단위에 가깝다.
- 종목과 투자 근거를 검색과 콘텐츠 흐름에서 다룰 수 있다.

단점:

- “투자 근거”가 Global Navigation에 직접 드러나지 않는다.

## 후보 2

- 홈
- 오늘의 시장
- 종목 찾기
- 내 분석
- 관심 변화
- 판단 기록

장점:

- 초보자에게 목적이 더 설명적이다.
- 종목 찾기 진입이 명확하다.

단점:

- 메뉴 수가 많고 Desktop과 Mobile을 동시에 만족시키기 어렵다.
- “종목 찾기”가 검색 기능처럼 보일 수 있다.

## 후보 3

- 홈
- 시장
- 투자 근거
- 분석 노트
- 관심 변화
- 판단 기록

장점:

- DATE의 차별점인 투자 근거가 잘 드러난다.
- 분석 노트와 판단 기록의 차이를 표현할 수 있다.

단점:

- 모바일 5개 항목 제한과 맞지 않는다.
- 투자 근거가 독립 화면처럼 과도하게 강조될 수 있다.

## 최종 권장안

Desktop Global Navigation:

- 홈
- 시장
- 분석
- 변화
- 기록

Mobile Bottom Navigation:

- 홈
- 시장
- 분석
- 변화
- 기록

보조 진입:

- 종목 검색
- 투자 근거 검색
- 관심 종목
- 알림
- 내 정보

## 화면별 제목 확장

메뉴는 짧게 유지하되 화면 제목은 더 구체적으로 쓴다.

- 홈: 오늘 시장 한눈에 보기
- 시장: 오늘의 시장
- 분석: 분석 중인 내용
- 변화: 새롭게 감지된 변화
- 기록: 투자 판단 기록
- 종목 상세: 종목 분석
- 투자 근거 상세: 투자 근거 확인

## 접근성 기준

- 현재 위치는 `aria-current`로 표현한다.
- Bottom Navigation은 최대 5개 항목만 둔다.
- 검색은 Bottom Navigation에 넣지 않고 상단 고정 검색 진입 또는 검색 버튼으로 제공한다.
- 종목 상세와 투자 근거 상세는 Bottom Navigation의 독립 항목으로 만들지 않는다.
