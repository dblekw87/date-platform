# Prototype A/B Comparison

## 비교 목적

Prototype A와 Prototype B는 우열 비교가 아니라 역할 비교 대상이다. Prototype A는 Product Architecture와 Core UX 검증 기준이며, Prototype B는 한국 투자 사용자 경험 검증 기준이다.

## Prototype A

- 글로벌 투자 리서치 도구형
- Evidence-first Architecture 검증
- 해외 금융 서비스 및 B2B SaaS에 가까운 화면 구성
- 영어 중심 용어
- 높은 정보 밀도
- Card와 Workspace 중심 구조
- 분석 도구에 가까운 인상

## Prototype B

- 한국 투자 사용자 경험형
- 한국어 중심
- 친숙한 시장 진입
- 설명형 정보 구조
- 모바일 친화
- Emotion Layer 포함
- 목록, 탭, 요약 중심
- 투자 근거 우선 원칙 유지

## 유지하는 기준

- Product Principles
- Entity Architecture
- Evidence Architecture
- 출처, 정보 최신성, 해석 범위 원칙
- 분석, 변화, 기록 책임 분리
- Core Domain 관계
- 검증된 사용자 흐름

## 재설계하는 기준

- 화면 언어
- Navigation
- Home 정보 구조
- 화면별 정보 우선순위
- 카드 / 목록 / 탭 / 표 사용 방식
- 모바일 흐름
- 상태와 도움말 문구

## 비교 평가 항목

1. 첫 진입 이해도
2. 정보 탐색 속도
3. 한국어 자연스러움
4. 시장 친숙도
5. 투자 근거 접근성
6. 정보 신뢰성 표현
7. 모바일 사용성
8. 정보 밀도
9. 다음 행동 명확성
10. DATE 차별성

## 실패 조건

Prototype B가 다음처럼 보이면 실패다.

- Prototype A를 한국어로 번역한 화면
- 해외 SaaS Layout에 한글만 입힌 화면
- 영어 단어를 강조 제목으로 사용하는 화면
- 모든 정보를 카드로 분리한 화면
- 시장 정보만 나열하고 투자 근거로 이어지지 않는 화면
- 투자 추천이나 수익 보장처럼 보이는 화면
