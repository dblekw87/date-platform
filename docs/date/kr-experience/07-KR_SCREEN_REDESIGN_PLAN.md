# KR Screen Redesign Plan

## 공통 전제

Prototype B는 `/kr` 하위 route에서만 구현한다. Prototype A 기존 route와 파일은 수정하지 않는다. 이번 문서는 화면 구현 전 재설계 방향만 정의한다.

## KR Phase 1: 한국형 Home Wireframe

목표:

- 오늘 시장 분위기를 5초 안에 이해한다.
- 시장 정보에서 투자 근거로 자연스럽게 이동한다.

권장 흐름:

1. 오늘 시장 한눈에 보기
2. 지금 확인할 주요 변화
3. KOSPI / KOSDAQ / 미국 주요 지수
4. 주목받는 테마
5. 거래대금 또는 관심이 높은 종목
6. 움직인 이유
7. 새로 확인된 투자 근거
8. 관심 종목에서 달라진 내용
9. 이어서 분석할 내용
10. 최근 판단 기록

## KR Phase 2: 한국형 시장 Wireframe

목표:

- 익숙한 시장 정보에서 시작해 투자 근거 기반 탐색으로 이어진다.

진입점:

- 오늘의 시장
- 상승·하락 종목
- 거래대금 상위
- 인기 종목
- 주목받는 테마
- 업종별 흐름
- 국내
- 미국
- ETF
- 주요 일정
- 새로 확인된 투자 근거

## KR Phase 3: 한국형 종목 상세 Wireframe

상단:

- 종목명
- 종목 코드
- 시장
- 현재가 Mock
- 등락률 Mock
- 거래량 Mock
- 관심 등록 Placeholder
- 한 줄 설명

탭 후보:

- 종합
- 투자 근거
- 주요 변화
- 재무
- 뉴스
- 토론

종합 우선순위:

1. 오늘 움직인 이유
2. 핵심 투자 근거
3. 아직 확인이 필요한 내용
4. 최근 주요 변화
5. 주요 수치
6. 관련 테마
7. 비슷한 종목
8. 분석에 추가하기

## KR Phase 4: 한국형 투자 근거 상세 Wireframe

권장 제목:

- 이 근거가 말하는 내용
- 어디에서 나온 정보인가
- 언제 확인된 정보인가
- 이 근거로 확인할 수 있는 내용
- 아직 단정할 수 없는 내용
- 추가로 확인해야 하는 정보
- 같은 판단을 뒷받침하는 근거
- 다른 해석이 필요한 근거
- 관련 종목과 시장 변화
- 분석에 추가하기

## KR Phase 5: 한국형 분석 Wireframe

목표:

- 사용자가 무엇을 분석 중인지, 어떤 근거를 비교 중인지, 무엇을 더 확인해야 하는지 알 수 있다.

유지 기능:

- 투자 근거 비교
- 종목 비교
- 주요 변화 확인
- 가설 정리
- 확인할 질문
- 다음 검토 항목

## KR Phase 6: 한국형 변화 Wireframe

목표:

- 가격 알림이 아니라 변화 감지와 검토 우선순위를 보여준다.

권장 문구:

- 새롭게 감지된 변화
- 먼저 확인할 변화
- 새로운 근거가 추가됐어요.
- 기존 판단과 다른 근거가 발견됐어요.
- 정보가 오래되어 다시 확인해야 해요.
- 관련 종목의 연결 정보가 달라졌어요.

## KR Phase 7: 한국형 기록 Wireframe

목표:

- 수익률 중심 매매일지가 아니라 판단 당시의 근거와 가설을 보존한다.

기록 항목:

- 당시 본 내용
- 세운 가설
- 내린 판단
- 판단한 이유
- 참고한 투자 근거
- 예상했던 조건
- 판단을 다시 봐야 하는 조건
- 이후 달라진 점
- 다음에 확인할 내용

## KR Phase 8: 전체 흐름 통합 및 A/B 비교

목표:

- Prototype A와 B를 비교하고 한국형 UX의 적합성을 검증한다.
- Home → 시장 → 종목 → 투자 근거 → 분석 → 변화 → 기록 흐름을 통합한다.
