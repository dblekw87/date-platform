# KR Mobile Strategy

## 기본 방향

Prototype B는 Desktop 축소판이 아니다. 한국 투자 서비스는 모바일 사용 비중을 중요하게 고려해야 하며, 모바일에서 먼저 자연스럽게 읽히는 구조를 기준으로 한다.

## Bottom Navigation

최대 5개 항목만 둔다.

- 홈
- 시장
- 분석
- 변화
- 기록

검색은 Bottom Navigation에 넣지 않는다. 상단 고정 검색 진입 또는 검색 버튼으로 제공한다.

종목 상세와 투자 근거 상세는 Bottom Navigation의 독립 항목으로 만들지 않는다. 검색 결과, 시장 화면, 관련 콘텐츠에서 진입한다.

## 모바일 화면 원칙

- 한 손 조작을 고려한다.
- 주요 CTA는 화면 하단 또는 손이 닿기 쉬운 위치를 검토한다.
- 탭은 필요한 경우 가로 스크롤을 허용하되 항목 수를 제한한다.
- 긴 정보는 접기·펼치기를 사용한다.
- 종목 목록과 투자 근거 목록은 충분한 터치 영역을 확보한다.
- 뒤로가기만으로 문맥을 이해하게 하지 않는다.
- 현재 보고 있는 종목과 투자 근거를 화면 안에 명확히 표시한다.

## 모바일 Home 전략

- 첫 화면 안에서 오늘 시장 요약과 주요 변화가 보여야 한다.
- 지수는 2열 또는 가로 목록으로 배치한다.
- 주목 테마와 많이 보는 종목은 목록 중심으로 배치한다.
- 투자 근거는 대표 1개와 목록형 보조 근거로 구성한다.

## 모바일 종목 상세 전략

- 상단에 종목명, 가격 Mock, 등락률 Mock, 관심 등록 Placeholder를 압축 배치한다.
- 탭은 `종합 / 투자 근거 / 주요 변화 / 재무 / 뉴스 / 토론`을 후보로 검토한다.
- 종합 탭은 “오늘 움직인 이유”와 “아직 확인이 필요한 내용”을 먼저 보여준다.

## 모바일 투자 근거 상세 전략

- 긴 원문처럼 보이지 않게 한다.
- 출처, 확인 시점, 단정할 수 없는 내용을 접기·펼치기와 요약으로 분리한다.
- 하단 고정 CTA 후보: `분석에 추가하기`

## 검증 Viewport

- `390x844`
- `360x800`
- `320x568`
- `768x1024`
- `1440x900`
- `1920x1080`

## 충돌 방지

Desktop에서 가능한 정보 밀도를 Mobile에 그대로 가져오지 않는다. Mobile에서는 정보 순서와 행동 위치를 우선하고, Desktop에서는 비교와 넓은 표를 보조로 사용한다.
