# KR Copywriting Guide

## 기본 어조

- 전문적이지만 어렵지 않다.
- 짧고 명확하게 쓴다.
- 번역투를 피한다.
- 투자 판단을 유도하지 않는다.
- 확인된 내용과 아직 확인되지 않은 내용을 분리한다.

## 화면 제목 예

- 오늘 시장 한눈에 보기
- 오늘 꼭 확인할 시장 변화
- 주목받는 테마
- 많이 보는 종목
- 새로 확인된 투자 근거
- 관심 종목에서 달라진 내용
- 이어서 분석할 내용
- 투자 판단 기록

## 버튼 문구 예

- 근거 확인하기
- 분석에 추가하기
- 이어서 분석하기
- 관련 종목 보기
- 다시 확인하기
- 기록 보기
- 시장으로 돌아가기

## 상태 문구 예

- 새롭게 감지된 변화
- 다시 확인이 필요해요.
- 아직 확인이 필요한 내용이 있어요.
- 출처가 확인된 정보입니다.
- 정보가 오래되어 다시 확인해야 해요.
- 다른 해석이 필요한 근거가 있어요.
- 분석에 사용 중인 근거입니다.

## 빈 화면 문구 예

- 아직 기록된 판단이 없어요.
- 새롭게 감지된 변화가 없어요.
- 연결된 투자 근거가 아직 없어요.
- 관심 종목을 추가하면 변화가 보입니다.
- 현재 조건에 맞는 종목이 없습니다.

## 오류 또는 미확인 상태 문구 예

- 확인되지 않은 종목입니다.
- 현재 준비된 투자 근거에 없는 항목입니다.
- 입력한 검색어와 연결된 결과를 찾지 못했어요.
- 다시 검색하거나 시장 화면에서 찾아보세요.

## 금지 문구

- 지금 매수하세요.
- 놓치면 안 되는 종목
- 무조건 오를 종목
- 급등 예상
- 오늘의 대박주
- AI가 추천하는 종목
- 확실한 기회
- 수익 보장

## Domain 용어 풀어쓰기

### 투자 근거

좋은 표현:

- 이 판단의 근거
- 새로 확인된 투자 근거
- 같은 판단을 뒷받침하는 근거

피할 표현:

- 에비던스
- Evidence

### 정보 최신성

좋은 표현:

- 언제 확인된 정보인가
- 마지막 확인 시점
- 다시 확인이 필요한가

피할 표현:

- Freshness
- 최신성 상태

### 해석 범위

좋은 표현:

- 이 근거로 확인할 수 있는 내용
- 아직 단정할 수 없는 내용
- 해석할 때 주의할 점

피할 표현:

- Boundary
- 근거 경계

### 현재 보고 있는 정보

좋은 표현:

- 현재 보고 있는 종목과 근거
- 이어서 분석 중인 내용
- 연결 정보

피할 표현:

- Context
- 컨텍스트
