# KR Validation Checklist

## 공통 평가 기준

- 첫 화면을 5초 안에 이해할 수 있는가
- 영어 UX 용어 없이도 사용할 수 있는가
- 오늘 무엇을 봐야 하는지 알 수 있는가
- 시장 정보에서 투자 근거로 자연스럽게 이동하는가
- 투자 근거와 해석을 구분할 수 있는가
- 아직 확인되지 않은 내용을 쉽게 찾을 수 있는가
- 다음 행동이 명확한가
- 모바일에서 한 손으로 주요 흐름을 사용할 수 있는가
- 카드가 과도하게 반복되지 않는가
- 투자 추천이나 수익 보장처럼 보이지 않는가
- 초보자에게 친절하면서 숙련 사용자에게도 정보가 부족하지 않은가

## 언어 검증

- 메뉴, 버튼, 탭, 상태, 도움말이 한국어인가
- 영어 UX 용어가 사용자 화면에 남아 있지 않은가
- 허용된 영어가 고유명사, 공식 약어, 종목 코드에 한정되는가
- 번역투 문장이 없는가
- Domain 용어가 설명형 한국어로 풀려 있는가

## Navigation 검증

- Desktop Global Navigation은 `홈 / 시장 / 분석 / 변화 / 기록`인가
- Mobile Bottom Navigation은 최대 5개 항목인가
- 검색은 상단 진입으로 제공되는가
- 종목 상세와 투자 근거 상세가 Bottom Navigation 독립 항목으로 들어가지 않았는가
- 현재 위치가 `aria-current`로 표현되는가

## Home 검증

- 오늘 시장 요약이 먼저 보이는가
- 주요 변화가 시장 지수보다 의미 있게 연결되는가
- 인기와 등락이 투자 판단처럼 보이지 않는가
- 움직인 이유와 확인된 투자 근거로 이어지는가
- 관심 종목 변화와 이어서 분석할 내용이 보이는가

## 시장 검증

- 순위표와 종목 목록만 나열하지 않는가
- 시장 변화, 테마, 종목, 움직인 이유, 투자 근거가 연결되는가
- 확인되지 않은 내용이 분리되어 보이는가

## 종목 상세 검증

- 한국 사용자가 익숙한 종목 정보가 상단에 있는가
- 가격과 차트가 투자 근거보다 화면 전체를 지배하지 않는가
- 종합 탭에서 움직인 이유와 핵심 투자 근거가 먼저 보이는가
- 아직 확인이 필요한 내용이 명확한가

## 투자 근거 상세 검증

- 출처와 확인 시점이 숨겨지지 않는가
- 이 근거로 확인할 수 있는 내용과 단정할 수 없는 내용이 분리되는가
- 같은 판단을 뒷받침하는 근거와 다른 해석이 필요한 근거가 구분되는가
- 분석에 추가하는 다음 행동이 명확한가

## 분석 / 변화 / 기록 검증

- 분석은 투자 근거 비교와 질문 정리에 집중하는가
- 변화는 가격 알림이 아니라 변화 감지와 검토 우선순위에 집중하는가
- 기록은 수익률 중심 매매일지가 아니라 당시 판단과 근거를 보존하는가

## Prototype A/B 비교 검증

- 첫 진입 이해도
- 정보 탐색 속도
- 한국어 자연스러움
- 시장 친숙도
- 투자 근거 접근성
- 정보 신뢰성 표현
- 모바일 사용성
- 정보 밀도
- 다음 행동 명확성
- DATE 차별성
