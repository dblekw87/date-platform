# KR Phase 1.5 Home Information Architecture

## 문서 목적

이 문서는 Prototype B Home을 구성하는 Information Block과 정보 흐름을 정의한다.

이번 문서는 화면을 그리지 않는다. route, component, wireframe, Figma 산출물을 만들지 않는다. 목적은 Home에서 어떤 정보가 어떤 순서와 관계로 배치되어야 하는지 정의하는 것이다.

## North Star

Home IA의 목표는 정보를 많이 보여주는 것이 아니다.

Home IA의 목표는 사용자가 오늘 시장에서 무엇을 먼저 봐야 하는지 이해하기 쉽게 배치하는 것이다.

성공한 Home은 사용자가 “뉴스를 많이 봤다”가 아니라 “오늘 시장을 이해했다”라고 느끼게 한다.

## 2. Section Dependency

### Hero

필요 정보:

- 오늘 가장 중요한 변화
- 공식 확인 상태
- 공개 시각
- 관련 종목
- 관련 테마
- 왜 중요한가
- 아직 확인되지 않은 내용 요약

의존 관계:

```text
공식 정보
→ 관련 종목·테마
→ 시장 반응
→ 확인된 사실
→ 미확인 내용
→ 다음 행동
```

### Market Snapshot

필요 정보:

- 주요 지수
- 환율
- 주요 자산
- 시장 상태
- 마지막 업데이트

의존 관계:

```text
시장 데이터
→ 기준 지수
→ 시장 분위기 요약
```

### Today Focus

필요 정보:

- 오늘 핵심 변화 후보
- 공식 출처 여부
- 관련 종목·산업·테마
- 공개 시각
- 중요도
- 미확인 내용

의존 관계:

```text
공식 공시 또는 공식 발표
→ 관련 산업
→ 관련 종목
→ 시장 반응
→ 투자 근거
```

### Theme Flow

필요 정보:

- 테마명
- 테마와 연결된 변화
- 관련 종목
- 확인된 근거 수
- 미확인 정보 여부

의존 관계:

```text
시장 변화
→ 관련 테마
→ 관련 종목
→ 움직인 이유
→ 투자 근거
```

### Watched Stocks

필요 정보:

- 종목명
- 종목 코드
- 시장
- 등락 Mock
- 거래대금 또는 관심도 Mock
- 움직인 이유 요약
- 관련 투자 근거

의존 관계:

```text
종목
→ 시장 데이터
→ 움직인 이유
→ 공식 근거
```

### Why Moved

필요 정보:

- 종목
- 공식 공시
- 공식 발표
- 뉴스
- 시장 데이터
- 관련 테마
- 확인된 사실
- 아직 단정할 수 없는 내용

의존 관계:

```text
종목
→ 공식 공시 또는 공식 발표
→ 뉴스
→ 시장 데이터
→ 확인된 사실
→ 아직 단정할 수 없는 내용
```

### Official Evidence

필요 정보:

- 투자 근거 ID
- 제목
- 공식 출처
- 공개 시각
- 확인 상태
- 마지막 업데이트
- 관련 종목
- 관련 테마

의존 관계:

```text
공식 출처
→ 공개 시각
→ 확인 상태
→ 관련 종목
→ 투자 근거 상세
```

### Need Confirmation

필요 정보:

- 미확인 내용
- 필요한 추가 정보
- 확인해야 하는 출처
- 다시 확인해야 하는 시점
- 관련 종목·테마

의존 관계:

```text
투자 근거
→ 아직 확인되지 않은 내용
→ 필요한 추가 출처
→ 재확인 시점
```

### Watchlist Changes

필요 정보:

- 관심 종목
- 새롭게 감지된 변화
- 관련 투자 근거
- 마지막 확인 시점
- 변화 상태

의존 관계:

```text
관심 종목
→ 새롭게 감지된 변화
→ 공식 정보 여부
→ 변화 상세
```

### Continue Analysis

필요 정보:

- 분석 중인 종목
- 분석 중인 투자 근거
- 아직 확인이 필요한 내용
- 마지막 분석 시점
- 다음 행동

의존 관계:

```text
이전 분석
→ 현재 보고 있는 종목과 근거
→ 아직 확인이 필요한 내용
→ 분석 화면
```

### Recent Decisions

필요 정보:

- 판단 기록
- 판단 시점
- 당시 참고한 투자 근거
- 이후 달라진 내용
- 다음 확인 조건

의존 관계:

```text
판단 기록
→ 당시 투자 근거
→ 이후 달라진 내용
→ 기록 상세
```

## 3. Information Priority

Priority는 고정 순서가 아니라 시장 상황에 따라 동적으로 바뀔 수 있어야 한다.

### 기본 Priority

| Priority | 정보 | 기본 위치 |
| --- | --- | --- |
| 1 | 오늘 반드시 확인해야 하는 변화 | Hero / Today Focus |
| 2 | 새롭게 확인된 공식 정보 | Hero / Official Evidence |
| 3 | 관심 종목 변화 | Watchlist Changes |
| 4 | 시장 전체 흐름 | Market Snapshot |
| 5 | 분석 이어가기 | Continue Analysis |
| 6 | 최근 판단 기록 | Recent Decisions |

### 장 시작 전

우선순위:

1. 오늘 시장 분위기
2. 공식 일정과 새 공시
3. 주요 지수와 환율
4. 관심 종목 변화
5. 이어서 분석

### 장 중

우선순위:

1. 새롭게 확인된 공식 정보
2. 관심 종목 변화
3. 움직인 이유
4. 주요 지수와 환율
5. 아직 확인되지 않은 내용

### 장 마감 후

우선순위:

1. 오늘 가장 중요한 변화 정리
2. 새로 확인된 투자 근거
3. 아직 확인되지 않은 내용
4. 이어서 분석
5. 최근 판단 기록

### 공식 정보가 적은 날

우선순위:

1. 오늘 시장이 조용한 이유
2. 주요 지수와 환율
3. 관심 종목 변화
4. 이어서 분석
5. 최근 판단 기록

## 4. Desktop Information Flow

Desktop은 넓은 화면을 사용하지만 Dashboard처럼 보이면 안 된다.

위에서 아래로 읽는 흐름:

1. Hero에서 오늘 가장 중요한 변화를 확인한다.
2. Market Snapshot에서 시장 기준점을 빠르게 확인한다.
3. Today Focus에서 핵심 변화 3개를 비교한다.
4. Theme Flow와 Watched Stocks에서 관련 테마와 종목을 탐색한다.
5. Why Moved에서 움직인 이유를 읽는다.
6. Official Evidence에서 공식 출처와 공개 시각을 확인한다.
7. Need Confirmation에서 아직 확인되지 않은 내용을 확인한다.
8. Watchlist Changes에서 개인 관심 종목 변화를 본다.
9. Continue Analysis와 Recent Decisions에서 이어서 할 행동을 정한다.

Desktop 배치 원칙:

- Hero는 화면 상단의 중심 정보를 담당한다.
- Market Snapshot은 Hero 아래 compact strip으로 둔다.
- Today Focus와 Why Moved는 읽는 흐름을 담당한다.
- Theme Flow와 Watched Stocks는 탐색 보조 영역이다.
- Official Evidence와 Need Confirmation은 신뢰 판단 영역이다.
- Continue Analysis와 Recent Decisions는 하단 개인 문맥 영역이다.

## 5. Mobile Information Flow

Mobile은 Prototype B Home의 기준 화면이다.

첫 화면 안에 반드시 보여야 하는 정보:

- 오늘 가장 중요한 변화
- 왜 중요한가 한 문장
- 공식 확인 상태
- 관련 종목 또는 테마
- Primary CTA

Mobile 순서:

1. Hero
2. Market Snapshot
3. Today Focus
4. Official Evidence
5. Need Confirmation
6. Theme Flow
7. Watched Stocks
8. Watchlist Changes
9. Continue Analysis
10. Recent Decisions

Mobile 원칙:

- 첫 화면에서 검색보다 오늘 시장 이해가 먼저다.
- 지수는 가로 Strip으로 훑게 한다.
- 테마는 탭 또는 가로 리스트로 둔다.
- 종목은 Compact Row로 둔다.
- 미확인 내용은 접기·펼치기로 제공한다.
- CTA는 한 손 조작 가능한 위치를 검토한다.

## 6. Expandable Area

Home은 모든 정보를 처음부터 펼쳐 보여주지 않는다.

### Need Confirmation

기본 노출:

- 미확인 내용 수
- 가장 중요한 미확인 내용 1개
- 다시 확인이 필요한 시점

펼치기:

- 미확인 내용 목록
- 필요한 공식 출처
- 관련 종목

상세:

- 투자 근거 상세 또는 분석 화면으로 이동

### Official Evidence

기본 노출:

- 대표 투자 근거 1개
- 출처
- 공개 시각
- 확인 상태

펼치기:

- 보조 투자 근거 목록
- 관련 종목과 테마

상세:

- 투자 근거 상세로 이동

### Theme Flow

기본 노출:

- 주요 테마 3~5개
- 연결된 변화 수

펼치기:

- 관련 종목
- 움직인 이유
- 공식 근거 수

상세:

- 시장 화면의 테마 상세 후보로 이동

### Watchlist Changes

기본 노출:

- 변화가 있는 관심 종목 수
- 가장 중요한 변화 1개

펼치기:

- 관심 종목별 변화 목록
- 확인 상태

상세:

- 변화 화면 또는 종목 상세로 이동

### Recent Decisions

기본 노출:

- 최근 판단 기록 1개
- 이후 달라진 내용 여부

펼치기:

- 최근 기록 목록

상세:

- 기록 화면으로 이동

## 7. Navigation Entry

각 Section의 이동 목적은 다음과 같다.

| Section | Primary Entry | Secondary Entry |
| --- | --- | --- |
| Hero | 투자 근거 상세 | 관련 종목 |
| Market Snapshot | 시장 | 해당 지수 관련 시장 정보 |
| Today Focus | 투자 근거 상세 | 관련 테마 / 관련 종목 |
| Theme Flow | 시장 | 관련 종목 |
| Watched Stocks | 종목 상세 | 움직인 이유 |
| Why Moved | 투자 근거 상세 | 분석 |
| Official Evidence | 투자 근거 상세 | 분석에 추가 |
| Need Confirmation | 분석 | 투자 근거 상세 |
| Watchlist Changes | 변화 | 종목 상세 |
| Continue Analysis | 분석 | 투자 근거 상세 |
| Recent Decisions | 기록 | 분석 |

Navigation 원칙:

- 매수, 매도, 추천으로 이동하지 않는다.
- 종목 상세와 투자 근거 상세는 콘텐츠 흐름에서 진입한다.
- 검색은 보조 진입이며 Home의 첫 목적이 아니다.

## 8. Empty State

### 공식 정보가 없는 날

표현:

- 오늘 새로 확인된 공식 정보는 아직 없습니다.
- 시장 분위기와 관심 종목 변화를 먼저 확인해보세요.

대체 노출:

- Market Snapshot
- 관심 종목 변화
- 이어서 분석
- 최근 판단 기록

### 시장이 조용한 날

표현:

- 오늘 시장은 큰 변화 없이 움직이고 있습니다.
- 새 공식 정보가 확인되면 이곳에 먼저 표시됩니다.

대체 노출:

- 주요 지수와 환율
- 주목받는 테마
- 이어서 분석

### 관심 종목이 없는 경우

표현:

- 관심 종목을 추가하면 새롭게 감지된 변화를 볼 수 있습니다.
- 먼저 시장에서 관련 종목을 찾아보세요.

대체 노출:

- 주목받는 테마
- 많이 보는 종목
- 시장 화면 진입

### 이어서 분석할 내용이 없는 경우

표현:

- 이어서 분석할 내용이 아직 없습니다.
- 오늘 확인된 투자 근거를 분석에 추가해보세요.

대체 노출:

- Official Evidence
- Today Focus

### 최근 판단 기록이 없는 경우

표현:

- 아직 기록된 판단이 없습니다.
- 분석을 마친 뒤 판단을 기록할 수 있습니다.

대체 노출:

- Continue Analysis
- Official Evidence

## 9. Loading State

### 실시간 데이터

대상:

- 주요 지수
- 환율
- 주요 자산
- 종목 등락 Mock

전략:

- 숫자 영역에는 skeleton 또는 점유 공간을 유지한다.
- 로딩 중에도 Section 높이가 크게 흔들리지 않아야 한다.
- “불러오는 중”보다 “시장 정보를 확인하는 중입니다.”처럼 설명형 문구를 사용한다.

### 공시와 공식 정보

대상:

- 공식 공시
- 공식 발표
- 거래소 또는 기관 정보

전략:

- 공식 정보 확인 중임을 명확히 표시한다.
- 확인 전 정보는 “미확인” 또는 “확인 중”으로 표시한다.
- 확인 완료 전에는 공식 정보처럼 표현하지 않는다.

권장 문구:

- 공식 정보를 확인하는 중입니다.
- 아직 공식 출처가 확인되지 않았습니다.

### 뉴스

대상:

- 관련 뉴스
- 보도 자료
- 기사 요약

전략:

- 뉴스는 공식 근거보다 낮은 위계로 둔다.
- 출처가 확인되지 않은 뉴스는 움직인 이유의 확정 근거로 쓰지 않는다.
- 로딩 중에는 뉴스 목록보다 공식 근거 영역을 우선 유지한다.

권장 문구:

- 관련 뉴스를 확인하는 중입니다.
- 뉴스는 공식 근거와 구분해서 표시됩니다.
