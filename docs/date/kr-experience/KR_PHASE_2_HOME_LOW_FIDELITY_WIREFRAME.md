# KR Phase 2 Home Low Fidelity Wireframe

## 문서 목적

이 문서는 KR Prototype B Home의 Information Architecture를 실제 화면 배치로 변환한다.

이번 문서는 디자인 문서가 아니다. 색상, 타이포그래피, 아이콘, 애니메이션, 시각 스타일을 결정하지 않는다. 목적은 레이아웃, 정보 배치, 화면 흐름, 섹션 간 우선순위를 검증하는 것이다.

## Scope

허용:

- Desktop / Tablet / Mobile 정보 배치 정의
- ASCII wireframe 작성
- Section별 높이, 넓이, 강조 정도 정의
- Interaction note 작성
- Responsive rule 작성

금지:

- 코드 작성
- Route 생성
- React Component 생성
- CSS 작성
- Figma 제작
- UI 스타일 결정
- 컬러 결정
- 타이포그래피 결정
- 아이콘 결정
- 애니메이션 결정

## 1. Desktop Wireframe

Desktop Home은 넓은 화면을 채우기 위해 위젯을 늘어놓지 않는다. 사용자가 위에서 아래로 읽으면서 “오늘 시장 → 중요한 변화 → 공식 근거 → 미확인 내용 → 이어서 할 행동”을 이해하도록 배치한다.

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ Global Header                                                                │
│ 홈 | 시장 | 분석 | 변화 | 기록                         종목·근거 검색        │
├──────────────────────────────────────────────────────────────────────────────┤
│ Hero: 오늘 먼저 볼 변화                                                      │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 오늘 꼭 확인해야 하는 변화가 있습니다.                                  │ │
│ │ 핵심 변화 / 왜 중요한가 / 공식 확인 상태 / 공개 시각                    │ │
│ │ 관련 종목 2~3개 / 관련 테마                                             │ │
│ │ [공식 근거 확인하기] [관련 종목 보기]                                   │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ Market Snapshot: 시장 기준점                                                 │
│ KOSPI | KOSDAQ | NASDAQ | S&P 500 | USD/KRW | 주요 자산                     │
├──────────────────────────────────────────────────────────────────────────────┤
│ Today Focus: 오늘 꼭 확인할 변화                                             │
│ ┌──────────────────────┬──────────────────────┬──────────────────────────┐ │
│ │ 변화 1               │ 변화 2               │ 변화 3                   │ │
│ │ 공식 확인 / 관련 종목│ 미확인 내용 요약     │ 근거 확인 진입           │ │
│ └──────────────────────┴──────────────────────┴──────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ Theme Flow + Watched Stocks                                                  │
│ ┌──────────────────────────────────────┬──────────────────────────────────┐ │
│ │ 주목받는 테마                         │ 많이 보는 종목                   │ │
│ │ 탭 또는 가로 리스트                   │ Compact Row 리스트               │ │
│ │ 테마 → 관련 종목 → 움직인 이유        │ 종목명 / 등락 Mock / 이유 요약   │ │
│ └──────────────────────────────────────┴──────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ Why Moved: 움직인 이유                                                       │
│ ┌──────────────────────────────────────────────────────────────────────────┐ │
│ │ 관련 종목 → 공식 정보 → 시장 반응 → 확인된 사실 → 단정할 수 없는 내용  │ │
│ └──────────────────────────────────────────────────────────────────────────┘ │
├──────────────────────────────────────────────────────────────────────────────┤
│ Official Evidence: 공식적으로 확인된 투자 근거                               │
│ 대표 근거 1개 + 보조 근거 리스트                                             │
│ 출처 / 공개 시각 / 확인 상태 / 마지막 업데이트                               │
├──────────────────────────────────────────────────────────────────────────────┤
│ Need Confirmation: 아직 확인되지 않은 내용                                   │
│ 기본 요약 + Accordion 펼치기                                                  │
├──────────────────────────────────────────────────────────────────────────────┤
│ Watchlist Changes: 관심 종목에서 달라진 내용                                 │
│ 관심 종목 변화 리스트                                                         │
├──────────────────────────────────────────────────────────────────────────────┤
│ Continue Analysis + Recent Decisions                                         │
│ ┌──────────────────────────────────────┬──────────────────────────────────┐ │
│ │ 이어서 분석                           │ 최근 판단 기록                   │ │
│ │ 분석 중인 종목과 근거                 │ 최근 판단 / 이후 달라진 점       │ │
│ └──────────────────────────────────────┴──────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

## 2. Mobile Wireframe

### Mobile: Fold 이전

첫 화면 안에는 오늘 가장 중요한 변화와 Primary CTA가 반드시 보여야 한다.

```text
┌──────────────────────────────┐
│ 상단: DATE        검색       │
├──────────────────────────────┤
│ Hero                         │
│ 오늘 꼭 확인해야 하는 변화   │
│ 왜 중요한가                  │
│ 공식 확인 / 공개 시각        │
│ 관련 종목 · 테마             │
│ [공식 근거 확인하기]         │
├──────────────────────────────┤
│ Market Snapshot              │
│ KOSPI | KOSDAQ | NASDAQ ...  │
└──────────────────────────────┘
하단 고정 메뉴: 홈 | 시장 | 분석 | 변화 | 기록
```

Fold 이전 필수 정보:

- 오늘 가장 중요한 변화
- 왜 중요한가 한 문장
- 공식 확인 상태
- 공개 시각
- 관련 종목 또는 테마
- Primary CTA
- 주요 시장 기준점 일부

### Mobile: Scroll 이후

```text
┌──────────────────────────────┐
│ Today Focus                  │
│ 변화 1                       │
│ 변화 2                       │
│ 변화 3                       │
├──────────────────────────────┤
│ Official Evidence            │
│ 대표 투자 근거               │
│ 보조 근거 리스트             │
├──────────────────────────────┤
│ Need Confirmation            │
│ 아직 확인되지 않은 내용      │
│ [펼치기]                     │
├──────────────────────────────┤
│ Theme Flow                   │
│ 테마 탭 / 가로 리스트        │
├──────────────────────────────┤
│ Watched Stocks               │
│ 종목 Compact Row 리스트      │
├──────────────────────────────┤
│ Why Moved                    │
│ 움직인 이유 설명 리스트      │
├──────────────────────────────┤
│ Watchlist Changes            │
│ 관심 종목 변화               │
├──────────────────────────────┤
│ Continue Analysis            │
│ 이어서 분석                  │
├──────────────────────────────┤
│ Recent Decisions             │
│ 최근 판단 기록               │
└──────────────────────────────┘
```

Mobile에서는 Official Evidence와 Need Confirmation을 Theme Flow보다 먼저 둔다. 이유는 모바일 사용자가 첫 진입 후 바로 신뢰 판단과 미확인 내용을 확인할 수 있어야 하기 때문이다.

## 4. Responsive Rules

### Desktop

- Header는 상단 전체 폭을 사용한다.
- Hero는 전체 폭 중심 영역으로 둔다.
- Market Snapshot은 Hero 아래 compact strip으로 둔다.
- Today Focus는 3개 항목을 같은 행에서 비교한다.
- Theme Flow와 Watched Stocks는 2열 배치를 검토한다.
- Why Moved, Official Evidence, Need Confirmation은 전체 폭 읽기 영역으로 둔다.
- Continue Analysis와 Recent Decisions는 하단 2열 배치를 검토한다.
- 화면이 넓어도 카드를 계속 늘리지 않는다.

### Tablet

- Header와 Hero는 전체 폭을 유지한다.
- Today Focus는 2열 또는 세로 stack으로 전환한다.
- Theme Flow와 Watched Stocks는 세로 배치한다.
- Market Snapshot은 가로 strip을 유지하되 화면 전체 overflow는 금지한다.
- CTA는 Section 내부에 둔다.

### Mobile

- Mobile을 기준 화면으로 본다.
- 첫 화면 안에 Hero와 Primary CTA가 보여야 한다.
- Bottom Navigation은 `홈 / 시장 / 분석 / 변화 / 기록` 5개 항목으로 제한한다.
- 검색은 상단 진입으로 둔다.
- Market Snapshot은 compact 가로 strip으로 둔다.
- Today Focus, Official Evidence, Need Confirmation을 Theme Flow보다 먼저 둔다.
- 종목과 투자 근거는 Compact Row와 리스트를 우선한다.
- Accordion은 Need Confirmation에 우선 적용한다.
- 내부 고정 패널이나 복잡한 분할 화면을 사용하지 않는다.

## 5. Visual Priority

시선 이동 순서:

1. 오늘 꼭 확인해야 하는 변화
2. 왜 중요한가
3. 공식 확인 상태와 공개 시각
4. Primary CTA
5. 주요 지수와 환율
6. 오늘 핵심 변화 3개
7. 관련 테마와 종목
8. 움직인 이유
9. 공식 투자 근거
10. 아직 확인되지 않은 내용
11. 관심 종목 변화
12. 이어서 분석
13. 최근 판단 기록

Visual Priority 원칙:

- Hero가 가장 강하다.
- Market Snapshot은 기준점이지만 Hero보다 강하면 안 된다.
- Official Evidence와 Need Confirmation은 신뢰 판단 영역으로 명확해야 한다.
- Theme Flow와 Watched Stocks는 친숙한 탐색 진입점이지만 추천처럼 보이면 안 된다.
- Recent Decisions는 Home 하단의 보조 문맥이다.

## 6. Interaction Notes

### Header

- 검색 버튼 또는 검색 입력은 상단에 둔다.
- 메뉴 현재 위치는 `aria-current`로 표현한다.
- Mobile에서는 Bottom Navigation과 역할이 충돌하지 않게 한다.

### Hero

- Primary CTA 클릭: 투자 근거 상세 또는 대표 근거 영역으로 이동한다.
- Secondary CTA 클릭: 관련 종목 영역 또는 시장 화면으로 이동한다.
- Hero 전체를 클릭 가능한 카드처럼 만들지 않는다.

### Market Snapshot

- Desktop: 각 지수는 compact row 또는 strip 항목으로 둔다.
- Mobile: 가로 scroll 가능.
- 지수 항목 클릭은 시장 화면으로 이동할 수 있다.
- 개별 지수를 종목 상세처럼 취급하지 않는다.

### Today Focus

- 각 변화 항목은 투자 근거 상세 또는 관련 종목으로 이동한다.
- 항목 전체 클릭은 허용하되 CTA 목적이 명확해야 한다.

### Theme Flow

- 탭 또는 가로 리스트 선택 시 Home 내부의 관련 변화와 종목이 갱신될 수 있다.
- Theme 선택이 즉시 종목 추천으로 이어지면 안 된다.

### Watched Stocks

- Row 클릭: 종목 상세로 이동한다.
- 보조 CTA: 움직인 이유 또는 투자 근거로 이동한다.

### Why Moved

- 설명 항목 클릭: 연결된 공식 근거로 이동한다.
- Hover는 Desktop 보조 정보 표시에만 사용한다.
- Mobile에서는 Touch target을 충분히 확보한다.

### Official Evidence

- 대표 근거 클릭: 투자 근거 상세로 이동한다.
- 보조 근거 펼치기 가능.
- 출처와 공개 시각은 숨기지 않는다.

### Need Confirmation

- 기본은 요약 노출.
- Accordion으로 펼치면 상세 미확인 항목과 필요한 추가 출처를 보여준다.
- 접힌 상태에서도 미확인 내용이 존재한다는 사실은 남아야 한다.

### Watchlist Changes

- 변화 항목 클릭: 변화 화면 또는 종목 상세로 이동한다.
- 관심 종목이 없으면 시장 화면 진입을 제공한다.

### Continue Analysis

- 클릭: 분석 화면으로 이동한다.
- 분석 결론처럼 보이면 안 된다.

### Recent Decisions

- 클릭: 기록 화면으로 이동한다.
- 수익률 평가처럼 보이면 안 된다.

## 7. Open Questions

1. Desktop에서 Theme Flow와 Watched Stocks를 항상 2열로 둘 것인가, 시장 상황에 따라 세로로 둘 것인가?
2. Mobile Fold 안에 Market Snapshot을 얼마나 보여줄 것인가?
3. Hero의 Secondary CTA는 `관련 종목 보기`와 `시장 더 보기` 중 무엇이 우선인가?
4. Official Evidence를 Why Moved보다 먼저 보여줘야 하는 시장 상황은 무엇인가?
5. Need Confirmation Accordion은 기본 접힘이 적절한가, 핵심 1개는 항상 펼쳐야 하는가?
6. 관심 종목이 없는 사용자에게 Watchlist Changes 위치를 유지할 것인가?
7. Continue Analysis와 Recent Decisions는 비로그인 상태에서 어떻게 표현할 것인가?
8. Desktop에서 우측 보조 영역을 완전히 배제할 것인가, 개인 문맥 영역에만 제한적으로 허용할 것인가?
