# US Macro News Board Direction

## 문서 목적

이 문서는 DATE 한국형 화면에서 미국시장 매크로 시황과 뉴스 흐름을 어떻게 표현할지 정리한다.

핵심 방향은 `이 뉴스 때문에 이 종목이 올랐다`를 말하지 않는 것이다. 단타 / 짧은 대응을 하는 사용자는 원인 단정표보다 시장 전체의 분위기, 매크로 변수, 헤드라인 흐름, 위험 선호, 다음 확인 지점을 빠르게 보고 대응 맥락을 잡아야 한다.

## Product Direction

DATE는 뉴스와 종목을 무리하게 1:1로 연결하지 않는다.

대신 다음 흐름을 보여준다.

```text
미국장 시황
  -> 뉴스 / 헤드라인 흐름
  -> 수급
  -> 차트 / 기술적 분석
  -> 시장 반응 구간
  -> 확인해야 할 이벤트
  -> 대응 전 확인할 조건
```

단, 소형주, 미국 저유동성 종목, 한국 테마주는 예외 구간으로 분리한다. 이 영역은 news-driven reaction이 실제로 강할 수 있으므로 뉴스와 종목 / 테마의 연결을 보여줄 수 있다. 하지만 이때도 `원인 확정`이 아니라 `뉴스 반응 감지`, `테마 연결 후보`, `유동성 / 급등락 주의`로 표현한다.

## 표현 원칙

| 원칙 | 설명 |
| --- | --- |
| Cause 대신 Context | `이것 때문에 올랐다`가 아니라 `현재 같이 확인해야 할 맥락`으로 표현한다. |
| 종목보다 시장 체온 | 첫 화면은 개별 종목보다 금리, 달러, 지수선물, 원자재, 리스크 선호를 먼저 보여준다. |
| 뉴스는 흐름으로 표시 | 개별 뉴스 하나를 결론처럼 쓰지 않고, 같은 방향의 headline cluster와 반대 headline을 함께 보여준다. |
| 수급은 두 번째 판단 재료 | 뉴스와 시황을 본 뒤 외국인 / 기관 / ETF / 거래대금 / 체결 강도를 확인한다. |
| 차트는 세 번째 판단 재료 | 기술적 분석은 시황, 뉴스, 수급 이후 진입 위치와 리스크를 확인하는 도구로 둔다. |
| 대응 언어는 조심 | 매수 / 매도 / 진입 / 손절을 직접 말하지 않고 `대응 전 확인`, `변수 유지`, `반응 확인`으로 쓴다. |
| 공식 / 비공식 분리 | FOMC, CPI, 실적, 공시 같은 공식 이벤트와 외신 / SNS / 시장 관찰을 분리한다. |
| 단정 대신 조건 | `상승 이유`보다 `이 조건이 유지되면 다시 확인`을 우선한다. |
| 뉴스 연결은 별도 구간 | 소형주 / 테마주 / 저유동성 종목은 `뉴스 반응 감지` 영역에서만 종목 연결을 보여준다. |

## 화면에서 먼저 보여줄 정보

1. 미국장 현재 분위기
2. 뉴스 / 헤드라인 흐름
3. 지수선물 / 금리 / 달러 / 원자재 / VIX
4. 수급
5. 차트 / 기술적 분석
6. 오늘 확인할 macro event
7. 시장 반응이 강한 구간
8. 아직 확인되지 않은 변수
9. 다음 확인 시점
10. 뉴스 반응 감지 구간

## 피해야 하는 표현

| 피할 표현 | 대체 표현 |
| --- | --- |
| `이 뉴스 때문에 상승` | `상승 구간에서 함께 확인된 뉴스` |
| `호재 / 악재 확정` | `긍정 / 부담 요인 후보` |
| `매수 대응` | `대응 전 확인 조건` |
| `관련주 급등 이유` | `관련 테마에서 확인할 변수` |
| `뉴스가 종목을 움직임` | `뉴스와 시장 반응이 같은 시간대에 관찰됨` |
| `뉴스발 급등주` | `뉴스 반응 감지 종목` |
| `재료 확정` | `재료 후보 · 원문 확인 필요` |

| --- | --- | --- |

## Wireframe 변경 방향

기존 `/kr/reference-board`는 검증 중심 구조를 유지하되, title과 정보 우선순위를 다음처럼 바꾼다.

- `속보를 종목 판단으로 바로 연결하지 않는 검증 중심 시장 보드`
- `미국장 매크로와 뉴스 흐름을 먼저 보는 대응 보드`

Main board는 다음 section을 우선한다.

- 미국장 분위기
- Headline flow
- Macro rail
- 수급
- 차트 / 기술적 분석
- 시장 반응 구간
- 대응 전 확인 조건
- Entity 후보는 하단 보조 정보
- 소형주 / 테마주는 별도 `뉴스 반응 감지` section으로 분리

## 다음 작업

1. `/kr/reference-board` copy를 cause-based wording에서 context-based wording으로 수정한다.
2. 시장 rail을 미국장 중심으로 재배열한다.
3. `영향 후보` panel을 낮추고, `대응 전 확인 조건` panel을 올린다.
4. headline item에서 종목 tag보다 macro variable과 event tag를 먼저 보여준다.
5. mobile 첫 화면에서 미국장 분위기와 macro rail이 먼저 보이게 한다.
6. 뉴스와 종목 연결은 `소형주 / 미국 잡주 / 한국 테마주` 전용 section으로 분리한다.
7. 화면 hierarchy를 `시황 / 뉴스 -> 수급 -> 차트 / 기술적 분석` 순서로 재정렬한다.
