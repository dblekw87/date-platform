# DATE Research Foundation

이 디렉터리는 신규 투자 플랫폼 **DATE — 투자 근거 연결 플랫폼**의 Product Research 문서 공간이다. 기존 Invest Community의 문서, 코드, 정보 구조, 화면 구조, 도메인 구조는 이 디렉터리의 기준이 아니다.

## Current Status

Phase 0은 Research Foundation 단계다. 이 단계는 조사 기준, 가설, 기록 형식, 평가 프레임을 준비한다. 실제 Benchmark 전체 분석, 최종 IA, 최종 Navigation, 최종 Entity Model, 최종 Screen System은 아직 수행하지 않는다.

## Source Boundary

DATE Research 문서는 다음 기준을 따른다.

- 기존 Invest Community를 개선 대상 또는 기준 구조로 사용하지 않는다.
- 경쟁 서비스는 복제 대상이 아니라 설계 이유를 분석하는 Benchmark로 사용한다.
- 확인한 사실, 해석, DATE 적용 가능성을 분리해서 기록한다.
- Research 완료 전에는 핵심 사용자, 중심 Entity, Navigation, 화면 체계를 확정하지 않는다.

## Shared Terms

- Hypothesis: 검증 전 제품 가설. Phase 0에서는 결정으로 취급하지 않는다.
- Observation: 실제 화면, 문서, 접근 조건에서 확인한 사실.
- Interpretation: 관찰된 구조가 왜 존재하는지에 대한 해석.
- Decision: Research 이후 근거를 바탕으로 선택한 방향. Phase 0에서는 생성하지 않는다.
- Entity: 투자 분석의 대상 또는 관계 노드 후보. Company, Security, Event 등은 검증 전 후보 용어다.
- Evidence: 투자 판단에 영향을 주는 원문, 데이터, 뉴스, 공시, 지표, 사용자 기록의 후보 단위다.
