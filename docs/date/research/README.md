# 문서 목적

이 README는 신규 투자 플랫폼 **DATE — 투자 근거 연결 플랫폼**의 Product Research 문서 묶음을 설명한다. 기존 Invest Community의 문서, 코드, Information Architecture, Screen 구조, 도메인 구조는 이 Research의 기준이 아니다.

## 범위

이 디렉터리는 DATE의 Phase 0 Research Foundation, Benchmark Research 기준, EidosLayer Phase 1 Research 산출물, Candidate Principle Registry를 포함한다.

현재 문서는 Research 기준과 Observation 기록을 관리한다. 최종 IA, 최종 Navigation, 최종 Entity Model, 최종 Screen System은 아직 확정하지 않는다.

## 작성 규칙

- 설명 문장은 한국어로 작성한다.
- Framework 용어는 영어로 유지한다.
- `Observation`, `Interpretation`, `Evidence`, `Hypothesis`, `Candidate Principle`, `Confidence`, `DATE Implication`은 번역하지 않는다.
- Observation과 Interpretation을 분리한다.
- Research 완료 전 DATE Architecture, Navigation, Entity Model, Screen System을 확정하지 않는다.
