# 문서 목적

이 README는 EidosLayer Phase 1 Research 문서 묶음의 범위와 사용법을 설명한다. 목적은 EidosLayer 기능을 나열하거나 DATE 구조를 확정하는 것이 아니라, 이후 TradingView, Koyfin, Finviz, Yahoo Finance, Bloomberg Terminal과 비교 가능한 Benchmark Evidence를 관리하는 것이다.

## 범위

이 문서 묶음은 EidosLayer의 공개 접근 가능한 Product Surface, Navigation, Screen, User Journey, Entity Candidate, Information Density, Trust/Evidence Pattern, Product Flow Architecture, Candidate Principle, Quality Review를 포함한다.

Access date는 2026-07-27이다. Access mode는 public, not logged in이다. Login Required, Paid Required, Unavailable, Not Verified 영역은 Observation과 분리해 기록한다.

## 작성 규칙

- 설명 문장은 한국어로 작성한다.
- Framework 용어는 영어로 유지한다.
- Observation과 Interpretation을 분리한다.
- Product Flow는 `Observed Flow`, `Partial Flow`, `Inferred Flow`, `Not Verified Flow`로 구분한다.
- Candidate Principle은 DATE의 Product Principle로 확정하지 않는다.
- 다음 Benchmark에서도 같은 12개 Scenario 구조를 사용한다.

## 주의사항

이 README는 EidosLayer Research 문서의 범위와 사용법만 설명한다. 새로운 Observation, Interpretation, Candidate Principle, DATE Architecture Decision을 추가하지 않는다.
