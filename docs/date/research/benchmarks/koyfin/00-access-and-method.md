## Secondary Source 사용 여부

Secondary Source는 사용하지 않았다.

검색 결과 요약은 공식 Koyfin URL에 연결된 Help Center 문서의 접근 보조로만 사용했다. 검색 결과 요약만으로 현재 Product 기능을 확정하지 않았다.

## 접근 제한

| Access Level | 기준 |
| --- | --- |
| Public Access | 로그인 없이 공식 Product page, Pricing, Help Center에서 확인 가능 |
| Login Required | App 내부에서 생성, 저장, 편집, Persistence 확인이 필요한 기능 |
| Paid Feature | Pricing에서 Plus, Premium, Advisor plan으로 제한된 기능 |
| Not Verified | 공식 문서에서 위치 또는 존재가 충분히 확인되지 않았거나 실제 App 조작이 필요한 항목 |

## 확인 수준

| Observation Status | 사용 기준 |
| --- | --- |
| Observed | 공식 Product page 또는 Pricing에서 직접 확인한 Product Surface |
| Partially Observed | 공개 Product page와 Help Center 설명이 함께 있으나 실제 App 내부 조작은 확인하지 못한 Surface |
| Official Documentation Only | Help Center에서만 확인한 App 내부 Surface 또는 기능 |
| Login Required | 로그인 후 App 내부 접근이 필요한 Surface |
| Paid Feature | Pricing에서 유료 plan 제한이 명시된 Surface 또는 기능 |
| Not Verified | 공식 자료로 독립 Surface 여부를 확인하지 못한 항목 |
| Inference | 공식 자료의 구조를 기반으로 한 Interpretation이며 Observation으로 사용하지 않는 항목 |

## Confidence 기준

| Confidence | 기준 |
| --- | --- |
| High | 공식 Product page, Pricing, 또는 Help Center가 Surface 명칭과 책임을 직접 설명한다. |
| Medium | 공식 Documentation이 App 내부 Surface를 설명하지만 실제 로그인 상태에서 직접 확인하지 못했다. |
| Low | 공식 자료가 일부 단서만 제공하거나 독립 Surface와 Capability 구분이 불완전하다. |

## Login Required 범위

다음 항목은 공개 문서에서 존재를 확인했지만 실제 App 내부 조작은 확인하지 못했다.

- My Dashboards 생성, 편집, 저장
- Dashboard widget 추가, 배치, resizing
- My Dashboard Groups 설정
- My Watchlists 생성과 view customization
- My Screens 생성과 저장
- My Portfolios 생성, holding 입력, account 관리
- My Graphs 저장과 folder 관리
- Command Bar 실제 검색 결과
- Right Sidebar 실제 상태와 ticker load behavior
- Alert 생성과 Persistence
- Returning User state 복귀
- customizable left navigation의 실제 사용자별 저장 상태
- My Graphs folder, saved graph, Present Mode 실제 Interaction

## Paid Feature 범위

Pricing 기준으로 다음 차이가 확인된다.

- Free plan은 2Y financials, 1Y estimates, 2 watchlists, 2 screens, 2 custom dashboards, limited company snapshots, limited news를 제공한다.
- Plus plan은 10Y financials, 10Y estimates, ETF holdings, Stock & ETF Screener, unlimited watchlists, unlimited screens, unlimited custom dashboards, 100K+ global company snapshots, filings, transcripts, premium news를 제공한다.
- Premium plan은 My Portfolio advanced analytics, unlimited custom data, formulas, custom financial templates, ETF valuation을 제공한다.
- Advisor plans는 model portfolios, client portfolios, reports, integrations, custom report pages 등을 제공한다.

## 알려진 조사 한계

- 실제 로그인 후 App 화면을 조작하지 않았다.
- 동적 App 화면의 Empty State, Loading State, Error State는 직접 확인하지 못했다.
- Mobile App은 공식 Product page 설명 기준이며 실제 Mobile UI 조작은 수행하지 않았다.
- Search 결과 grouping, Search ranking, keyboard interaction의 세부 동작은 Help Center 설명 기준이다.
- Portfolio, Watchlist, Dashboard Persistence는 공식 Documentation과 Pricing 기준이며 실제 저장 동작은 확인하지 않았다.
- 유료 plan 기능은 Pricing과 Help Center 설명 기준이며 실제 유료 계정으로 검증하지 않았다.
- Phase 3.2의 Journey는 공식 Product page와 Help Center에서 확인 가능한 경로 단서만 사용했다. 실제 클릭 수는 확인하지 못한 경우 `Not Verified`로 기록한다.
- Phase 3.3의 Product Flow는 Phase 3.1과 Phase 3.2 Observation을 통합한 것이다. 실제 App에서 확인하지 못한 관계는 `Official Documentation Only`, `Inference`, `Not Verified`로 분리한다.
- Phase 3.4는 새로운 Source를 추가하지 않았다. 기존 Phase 3.1~3.3 문서의 Evidence 상태와 Pattern readiness만 재분류했다.
