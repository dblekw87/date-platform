# Pattern Inventory

## 문서 목적

이 문서는 7개 Benchmark에서 나온 Observation과 Candidate Principle을 Benchmark 중심이 아니라 Product Pattern 중심으로 재분류한다.

Pattern ID `PT-001 ~ PT-030`은 Cross Benchmark 비교용 ID이며 Candidate Principle ID가 아니다. Related Principles는 기존 Registry `P-001 ~ P-030`에만 연결한다.
