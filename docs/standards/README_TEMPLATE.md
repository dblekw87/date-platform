# README Template 문서

아래 구조는 DATE 프로젝트의 모든 README에 적용한다.

```markdown
# 문서 목적

이 README가 설명하는 문서 묶음의 목적을 한국어로 작성한다.

## 범위

이 디렉터리 또는 문서 묶음이 포함하는 범위를 작성한다.

## 문서 구성

- [file-name.md](file-name.md): 문서 역할을 한국어로 설명한다.

## 작성 규칙

- 설명은 한국어로 작성한다.
- Framework 용어는 영어로 유지한다.
- Observation과 Interpretation을 분리한다.
- Research 완료 전 DATE Architecture를 확정하지 않는다.

## 관련 문서

- [DOCUMENTATION_STANDARD.md](DOCUMENTATION_STANDARD.md)
- [TERMINOLOGY.md](TERMINOLOGY.md)

## 주의사항

이 README는 문서 사용법과 범위를 설명한다. 새로운 Research 결과나 Product Decision을 추가하지 않는다.
```
